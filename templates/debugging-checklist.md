# Five-question debugging checklist

Ask in order for any wrong answer. Stop at the first "no."

1. **Context:** was every fact needed for the right answer in the folder?
2. **Memory:** did the agent have what the user already told it?
3. **Tools:** did each tool run, succeed, and return current data?
4. **Harness:** did every rule that applies get checked in code?
5. **Model:** with a correct folder, correct facts, and the rules in place, did the model still get it wrong? Check temperature and instructions.
