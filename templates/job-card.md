# Job card

One page describing what your assistant does and how you will know it works. Fill it in before you build. About half an hour.

| | |
| --- | --- |
| **Who it's for** | |
| **The job** (one sentence) | |
| **Done looks like** | |
| **Facts it needs, and where each comes from** (context, memory, or a tool; how fresh) | |
| **Actions, and the ladder step for each** (suggest, draft, act with undo, act within limits) | |
| **Must never** (three at most, each enforced in code) | |
| **Out of scope** | |
| **How we'll measure** (test set size, the checks, which matter most) | |
| **Today's baseline** (volume, time per request, error rate, cost) | |
