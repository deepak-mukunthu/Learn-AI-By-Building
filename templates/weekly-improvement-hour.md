# Weekly improvement hour

- **10 min:** pull 20 conversations with a failure signal (rephrasing, asking for a person, giving up).
- **20 min:** read the traces; tag the part at fault for each.
- **10 min:** group them; pick the highest impact (how many × how bad).
- **15 min:** write the fix as one change in one part; add 2 or 3 failures to the test set.
- **5 min:** after the fix ships, re-run the tests and record before and after.
