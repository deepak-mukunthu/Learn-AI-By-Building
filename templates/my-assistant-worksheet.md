# My Assistant worksheet

Start in Start Here and add a line each chapter.

Pick one small assistant you'd like to exist, for yourself, a team, or a club. Fill in one line as you finish each chapter. If you don't have suitable documents of your own, use the [Northwind pack](builders/northwind-document-pack.md).

| Line | After | Write down | Your answer |
| --- | --- | --- | --- |
| 1 · Job | Ch 1 | The job in one sentence. Three facts it needs that no model learned in training. Two test questions with the answers you'd expect. | |
| 2 · Parts | Ch 2 | One line each for model, context, memory, tools, and harness. | |
| 3 · Sources | Ch 4 | The documents it may use, who keeps each current, and one it must never see. | |
| 4 · Memory | Ch 5 | What it keeps, for how long, and how someone clears it. | |
| 5 · Actions | Ch 6-7 | What it may look up, what it may change, and for each change the rule and who approves. | |
| 6 · Tests | Ch 8 | Ten test questions with expected answers, including your two from line 1 and at least two "must never" cases. | |
| 7 · Sharing | Ch 11 | Who tries it first, how they report a problem, and how you turn it off. | |
